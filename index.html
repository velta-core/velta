The Velta network

Velta combines a peer-to-peer node network, Proof-of-Work consensus, wallet transactions and an independently verifiable blockchain.

The network is designed so each compatible node verifies blocks and transactions according to the same consensus rules. Modified clients cannot simply create valid VT or rewrite accepted history unless their blocks satisfy the rules accepted by the network.
