Official Velta Project

Velta: digital currency, mining and community in one peer-to-peer network.

Velta brings wallet, mining, blockchain verification, community and direct communication together in one open-source application. The network is designed to operate peer to peer: there is no single central server that owns the blockchain or decides by itself which transactions are valid.

Understanding Velta

What is Velta?

Velta is software, a digital currency, a peer-to-peer network and a blockchain working together. A compatible computer can participate directly in the network instead of depending on one central server to hold the official database.

In a traditional online service, your computer usually talks to a company's server and that server decides what the official data is. Velta works differently. Computers running Velta talk to other Velta computers. They exchange transactions and blocks, then each compatible node checks the rules for itself.

This means there is no single machine that can simply change everyone's balance, approve a false transaction or rewrite the blockchain alone. The network reaches its accepted history by following the same public consensus rules across participating nodes.

A participant can create a wallet, receive VT, send VT, mine blocks, inspect blockchain activity, communicate with other participants and use the social tools integrated into the application.

The objective is to make participation understandable and practical. A person does not need to run a separate miner, wallet, community client and blockchain explorer: these tools can exist together in the Velta software.

Every compatible node follows consensus rules that define valid transactions, valid blocks, mining difficulty, issuance and the maximum monetary supply. Because the project is open source, these rules can be inspected independently rather than hidden behind a private server.

Peer-to-peer network

No central blockchain server

Velta is designed so the blockchain is not owned by one central server. Nodes communicate directly with peers, exchange transactions and blocks and independently verify whether the information follows the protocol.

Accessible mining

Mining designed to be easier to control

One of the goals of Velta is to make participation in mining understandable for ordinary computer users. Mining controls are integrated directly into the application instead of requiring a separate command-line miner.

GPU

GPU mining

Compatible graphics hardware can be used for Proof-of-Work computation.

Usage limiter

The miner can limit average GPU usage from 50% to 100%, allowing the computer to retain resources for other tasks.

°C

Temperature limit

When GPU telemetry is available, the user can choose a thermal limit and Velta can stop mining if the GPU reaches it.

These controls affect only the local miner. They do not change network difficulty or block validity.

About possible value: Mining rewards participants with VT according to the protocol. Like other open digital assets, VT may or may not acquire market value in the future depending on adoption and demand. Velta does not promise appreciation, profit or financial return.

Voice calls are integrated into the community experience. A participant can call a friend without leaving the Velta application.

The current voice engine uses WebRTC technology for real-time audio, microphone handling, network negotiation and echo-processing capabilities.

ART BLOCKS

Rare digital items linked to mining

Velta includes Art Blocks, a native system for rare digital items associated with eligible blocks in the blockchain.

The idea is different from simply uploading an image to a centralized NFT service. Eligibility is determined by rules recognized by the Velta network, allowing other compatible nodes to verify whether an Art Block belongs to a legitimate block.

Art Blocks connect mining, rarity, blockchain history and digital ownership in the same protocol, making them one of the distinctive experimental features of Velta.

About the creator

Why I created Velta

KAMACHI

KAMACHI

I created Velta as an independent software and peer-to-peer digital currency project. The idea was to build something I could understand from the inside and then make available as an open network that other people can inspect and participate in.

I wanted Velta to be approachable. A person should be able to install the software, create a wallet, connect to peers, mine using a compatible computer, inspect the blockchain and communicate with other participants without needing a collection of separate programs.

The project was not created to give me a privileged financial position over everyone else. The objective is for the network rules to be public, for the software to be inspectable and for official releases to have a clear public source.

Development has involved real tests between multiple computers: mining, wallet transfers, blockchain synchronization, recovery, community communication, voice calls and Art Blocks. The purpose of these tests was to expose problems before making the software public.

Transparency about development wallets

Two wallets were used exclusively during development for testing mining, transactions, synchronization and Art Blocks. The blockchain records generated during these tests are part of the technical history of the development chain and should not be rewritten simply to conceal that testing occurred. Local wallet files may be removed from the development computers, and these wallets are not intended for commercial trading, sale or financial advantage by the project creator.
