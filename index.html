Understanding Velta

What exactly is Velta?

Velta is software, a peer-to-peer network and a digital monetary system operating together. Instead of relying on one central computer to decide which transactions are valid, multiple independent Velta nodes maintain and verify a shared blockchain.

A user can create a wallet, receive VT, send VT directly to another wallet and independently inspect the blockchain. Miners provide computational work to organize transactions into blocks and protect the history of the network.

Every compatible node follows the same consensus rules. Those rules define what a valid transaction is, how blocks are connected, how mining difficulty behaves, how new VT can be issued and how the total monetary supply is limited.

Because the project is open source, the objective is not to ask users to trust a hidden server or hidden accounting system. The software and protocol can be inspected, tested and compared by independent participants.

Computers forming one shared blockchain

Velta is not a website database stored on one machine. Compatible computers communicate with peers, exchange transactions and blocks, and independently verify whether the information follows the protocol.

Why old blocks are difficult to change

Every block references information from the previous block. Changing historical data changes its cryptographic hash and breaks the relationship with the blocks that follow it.

Network security

Mining Velta

Velta uses Proof-of-Work. Mining software performs computational work in an attempt to create a valid block. Other nodes do not simply trust the miner: the block must still satisfy the consensus rules before being accepted.

GPU

GPU mining

Thermal protection

When supported by the hardware, Velta can monitor GPU temperature and stop mining at a configured limit.

ART BLOCKS

Rare digital items created by the blockchain

Velta includes Art Blocks, a native system for rare digital items associated with eligible blocks.

The purpose is different from simply uploading an image to a centralized database. Eligibility is based on rules recognized by the Velta network, allowing compatible nodes to verify whether an Art Block is legitimate.

This makes Art Blocks a native part of the Velta experiment: mining, blockchain history, rarity and digital ownership are connected in the same network.

About the creator

Why I created Velta

KAMACHI

KAMACHI

I created Velta as an independent software and peer-to-peer digital currency project. My goal was to understand, build and make available a network in which transactions, mining and blockchain history can be independently verified.

Velta was not created as a mechanism for giving me a privileged financial position over other participants. I want the protocol rules to be visible, the software to be inspectable and the network to evolve through public and verifiable code.

The development process has included real mining, transactions between computers, network synchronization, wallet recovery tests, Art Block tests and repeated experiments intended to expose technical problems before any public launch.

The official GitHub repository exists to provide a public reference for the original project, its source code and official releases.

Development wallet transparency

Two wallets were used during development exclusively for technical testing of mining, transactions, synchronization and Art Blocks. Blockchain records created during these tests form part of the historical development chain and should not be artificially rewritten simply to hide the tests. The local wallet files may be removed from development computers, and these wallets are not intended for commercial trading, sale or financial advantage by the project creator.
